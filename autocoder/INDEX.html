--- ## 🚀 Getting Started ### Step 1: Clone & Navigate ```bash git clone cd autocoder ``` ### Step 2: Setup Backend ```bash cd backend python -m venv venv source venv/bin/activate # Unix venv\Scripts\activate # Windows pip install -r requirements.txt cp .env.example .env # Edit .env and add GROQ_API_KEY ``` ### Step 3: Setup Frontend ```bash cd ../frontend npm install ``` ### Step 4: Run ```bash # Terminal 1: Backend cd backend source venv/bin/activate uvicorn app.main:app --reload # Terminal 2: Frontend cd frontend npm run dev ``` ### Step 5: Access - Frontend: http://localhost:5173 - Backend: http://localhost:8000 - API Docs: http://localhost:8000/docs ### Step 6: Generate Enter a prompt like: > "Create me a jewelry website with shopping cart and checkout" --- ## 📊 What You Get ### Generated Project Structure ``` project-{id}/ ├── frontend/ # Complete React app ├── backend/ # Complete FastAPI server ├── database/ # SQLite schema & migrations ├── docker-compose.yml # Ready to deploy ├── .env # Configuration └── README.md # Setup instructions ``` ### Generated Frontend - React components (TypeScript) - Custom hooks - React pages with routing - TailwindCSS styling - State management ### Generated Backend - FastAPI routes - SQLAlchemy models - Business logic services - Input validation - Error handling ### Generated Database - SQLite schema - Database migrations - Seed data - Indexes & constraints --- ## 🔧 Technology Stack
